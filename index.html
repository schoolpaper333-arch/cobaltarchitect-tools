AI 위임 관리 보드

서류마다 왜 있는지부터 묻고, 없앨 것 · AI에게 맡길 것 · 사람이 정할 것으로 나눕니다. 에이전트에게 맡긴 일과 확인한 내용을 적어 둡니다.

서류 진단

서류 이름과 목적을 적고, 질문 세 개에 답합니다. 목적이 비어 있으면 진단하지 않습니다.

예: 지원 탈락, 허가 거부, 징계, 급여·평가에 영향이 있는 경우. 아니오: 내부 보고서 작성, 자료 취합만 하는 경우. 잘 모르겠으면 “모르겠음”을 고르세요. 모르면 사람이 직접으로 분류합니다.

진단한 서류

맡긴 일 목록

이름과 맡긴 일만 적으면 됩니다. 범위와 확인 주기는 기본값(초안까지 · 매번)으로 들어갑니다.

확인 기록

날짜는 오늘로 자동 입력됩니다. 에이전트와 무엇을 살펴봤는지 한 줄만 적으면 됩니다.

한눈에 보기

핵심 업무는 가끔 직접 해 보며 감을 잃지 않습니다.

사용법

1. 서류 진단

서류 이름과 “이 서류는 왜 있나”를 적고, 질문 세 개에 답합니다.

2. 4칸 분류

질문 순서대로 자동 분류됩니다. 없앨 후보 / AI에게 맡김 / AI 초안 + 사람 결정 / 사람이 직접. 잘 모르겠으면 사람이 직접으로 분류됩니다.

3. 맡긴 일 목록

AI에게 맡김 또는 AI 초안 + 사람 결정인 서류만 목록에 붙일 수 있습니다. 에이전트 이름과 맡긴 일을 적으면 됩니다.

4. 확인 기록

무엇을 살펴봤는지 한 줄을 적어야 저장됩니다. 확인했다는 표시만 남기지 않습니다.

5. 한눈에 보기

분류별 개수, 에이전트별 마지막 확인일, 확인 주기가 지난 표시를 봅니다. 이번 달 핵심 업무를 직접 해 봤는지 체크합니다.

예시 넣기 버튼을 누르면 서류 5개와 목록, 확인 기록이 바로 채워집니다. JSON 내보내기로 파일을 저장해 두면 다른 기기에서도 불러올 수 있습니다.

입력한 내용은 어디로도 보내지 않습니다. 저장은 이 브라우저 안에만 합니다.
